# How AI Agents Actually Work: A Technical Deep-Dive

**3-hour hands-on workshop for founders and dev teams**

Stop wrapping API calls and calling it "AI." Learn the architecture that powers production AI coding assistants — and build one yourself.

## What You'll Build

In 3 hours, you'll go from zero to a working AI agent with:

- A **tool loop** that lets an LLM read files, run commands, and search the web
- **Safety hooks** that block dangerous operations and redact secrets
- An **MCP server** that connects any database to any AI agent
- A clear path from prototype to product

## Who This Is For

- Technical founders building AI-powered products
- Dev leads evaluating AI agent frameworks
- Engineers who want to understand what's under the hood

Basic programming experience required. Any language — we'll work in Python.

## What You'll Learn

1. **The Agent Loop** — Why an LLM + tools is fundamentally different from a chatbot
2. **Tool Orchestration** — Sequential, parallel, conditional, and recursive patterns
3. **Production Safety** — Hooks that let you deploy agents without shipping liabilities
4. **MCP Integration** — The emerging standard for connecting data sources to AI
5. **From Prototype to Product** — Pricing models, deployment, and client delivery
